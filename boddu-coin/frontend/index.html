🔧 Technical Architecture

Smart contract implementation details

Token Contract (ERC-20)

  • Standard: ERC-20 (OpenZeppelin v5.0)
  • Solidity: ^0.8.20 with optimizer (200 runs)
  • Features: Burnable, Ownable, Custom Events
  • Access Control: Owner-only minting via OpenZeppelin Ownable
  • Gas Optimized: Uses immutable variables, optimized storage

Faucet Contract

  • Security: ReentrancyGuard to prevent reentrancy attacks
  • Rate Limiting: Cooldown period between claims
  • Tracking: Per-address claim history & leaderboard
  • Admin: Configurable drip amount, emergency withdrawal
  • Events: TokensClaimed, FaucetRefilled, ConfigUpdated

Frontend Stack

  • Web3: Ethers.js v5.7 for blockchain interaction
  • Wallet: EIP-1193 provider (any injected wallet)
  • Hosting: GitHub Pages (static, decentralized-friendly)
  • No Backend: 100% on-chain, trustless operation

Security Considerations

  • ✅ ReentrancyGuard on all state-changing functions
  • ✅ Checks-Effects-Interactions pattern
  • ✅ No external calls before state updates
  • ✅ Integer overflow protection (Solidity 0.8+)
  • ✅ Access control with OpenZeppelin Ownable
